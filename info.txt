
1. backend/document_service.py -- This is the core file. It handles:
PDF text extraction (via PyPDF2)
Word/DOCX text extraction (via python-docx)
In-memory document store (upload, list, get, delete)
2. The Document API endpoints (currently embedded inside backend/api.py, lines 401-489) -- These are the 4 REST endpoints:
POST /api/documents/upload -- upload a PDF/Word file
GET /api/documents -- list uploaded documents
DELETE /api/documents/{doc_id} -- remove a document
POST /api/documents/chat -- ask a question about a document
